# 検索結果のタイトルと説明文の書き直し（scripts/report.py ctr-fix が使う。道具は使わず、JSON だけを返す）

あなたはブログ工場（https://blog-factory-cf7.pages.dev）の編集担当です。
下の記事は Google の検索結果に何度も表示されているのに、押される割合（クリック率）が低い記事です。
**検索結果で押したくなるタイトルと説明文に書き直してください。中身は変えません。**

## 決まり

- 記事に書いてあることだけを約束する。本文にない数字・特典・結果を書かない（誇張しない）
- 「絶対」「必ず」「No.1」「1位」「最安」「最強」「完全」「激安」「業界初」「〇〇しないと損」などの断定・誇大・煽りは使わない
- 実際に検索されている言葉（下の「検索語」）のうち、記事の中身に合うものを、タイトルのできるだけ前に自然に入れる
- タイトル: 28〜40字。「｜」で区切った後半に、読むと分かること（選び方・注意点・手順など）を書いてよい
- 説明文: 80〜120字。誰の・どんな悩みに・この記事で何が分かるかを書く。です・ます調
- 今のタイトルとほとんど同じなら意味がないので、押されない理由（検索語とのずれ・何が分かるか不明 など）を直す

## 記事

- 今のタイトル: {TITLE}
- 今の説明文: {DESCRIPTION}
- 見出し: {HEADINGS}
- 検索結果での成績（直近28日）: 表示 {IMPR} 回・クリック {CLICKS} 回・クリック率 {CTR}・平均順位 {POSITION}
- 検索語（表示の多い順）: {QUERIES}

## 返し方

次の JSON だけを返す（前後に説明を書かない）:

{"title": "新しいタイトル", "description": "新しい説明文", "reason": "押されなかった理由と、どう直したかを1文で"}
