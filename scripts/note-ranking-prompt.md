## やること

1. **新しい自動化の道具**: WebSearch で、ここ数か月に出た・広まった、暮らしや仕事の作業を自動化する道具・サービスを探す。
   見つけたら WebFetch で**公式サイト（運営会社のサイト）**を開き、名前と、何を自動化できるかを確かめる。
   - 今のランキングの項目に合う道具なら `tools` に入れる（1項目に1〜2個・全体で10個まで）
   - 今のランキングにない「毎回の面倒」で、その道具で自動化できるものなら `new_items` に入れる（5個まで。無理に作らない）
2. **コメントの「面倒」**: 上のコメントに、読者自身の面倒な作業が書かれていれば、いちばん近いランキングの項目（困りごとの文字をそのまま）に結びつけて数える（`comment_hits`）。
   あいさつ・感想だけのコメントは数えない。近い項目がなければ数えない
3. 保存したら「保存しました」とだけ報告して終わる

## 確かめ方のルール

- 書いてよいのは公式サイトに書いてあることだけ。比較サイト・ブログ・まとめ記事・口コミは根拠にしない
- 料金は書かない（変わるため）。「No.1」「◯％削減」などの宣伝の数字も写さない
- 公式サイトが見つからない・開けない道具は入れない
- 道具の名前は公式サイトの表記どおり

## 保存する形（JSON）

```json
{
  "checked": "{TODAY}",
  "tools": [
    {"困りごと": "<今のランキングの困りごと（文字をそのまま）>", "name": "<道具の名前>", "url": "<公式サイトのURL>", "checked": "{TODAY}"}
  ],
  "new_items": [
    {"困りごと": "<短い名詞句>", "分野": "<家事 / 会社員 / お金 / 個人事業主 / 飲食店 / 健康・学び / 経理・事務 / 子育て・家族 / 美容室・サロン / 小売・ネットショップ / 建設・リフォーム / 教育 / 介護 / 不動産・管理 / SNS・発信 / 医療・クリニック のどれか>",
     "今のやり方": "<今どうしているか。短く>", "自動化の方法": "<道具・仕組みで何をどう任せるか。1文>", "道具の例": "<道具の種類（例: 予約システム）>",
     "困っている人の多さ": 1, "自動化のしやすさ": 1, "すぐ使える道具": 1,
     "公式サイト": "<確かめた公式サイトのURL>", "道具": [{"name": "<道具の名前>", "checked": "{TODAY}"}]}
  ],
  "comment_hits": {"<今のランキングの困りごと>": 1},
  "notes": "<確かめられなかったことがあれば一言。なければ空>"
}
```

- 点（困っている人の多さ・自動化のしやすさ・すぐ使える道具）は 1〜5 の整数。根拠が弱いときは低めにつける
- 何も見つからなければ、`tools`・`new_items` は空の配列、`comment_hits` は空のオブジェクトで保存する
