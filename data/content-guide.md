# 書き方のルール（X・note 共通の土台と、それぞれのルール）

目的：読んだ人が「おっ、この投稿おもしろい。このアカウントをフォローしたい」と思う投稿・記事にする。
X の文章を作るプロンプト（scripts/x-prompt.md）は、毎回この中の「共通の土台」と「X のルール」を読み込む（scripts/x-plan.py が差し込む）。
note のルールは note 担当が反映する（この下に「## note のルール」として足す）。

---

## 共通の土台（X・note どちらも）
- 「誰が書いても同じ一般論」は書かない。この発信者にしか書けない材料を使う：
  - 元飲食店経営者としての実体験（閉店後の締め作業、シフト、電話予約など）
  - 実際に作ったもの（住宅点検のカルテ発行・見積、飲食店のレジ・モバイルオーダー、問い合わせ受付）
  - 自動化ランキングの調査データ（何位か、なぜ面倒か）
- 数字は本物だけ。作り話の事例・お客さんの声は書かない。お客さんが特定できる情報は出さない。
- 誇張・断定・煽り（「必ず」「誰でも」「月◯万円」）は使わない。
- このアカウント自体が自動で動いていることに触れない。

## X（@maf_media_jp）のルール
### 1行目
- 手を止めさせる一文から始める（30字以内）。型：
  - 問いかけ：「見積書の数量、何回打ち直してますか。」
  - 意外な事実：「経理で一番面倒なのは、計算じゃなく転記でした。」
  - 体験の一言：「飲食店をやっていた頃、毎晩の締めが一番つらかった。」

### 投稿の型（日替わりで回す）
1. 実物を見せる型：作ったものの画面（ダミーデータ）＋何が変わったか
2. 体験＋意見の型：飲食店時代などの実体験から、言い切りすぎない意見を1つ
3. まとめの型：「◯◯の面倒トップ3、いまある道具で減らせます」＋番号付き3行
4. Before/After の型：「前：◯◯／今：◯◯」を画像で見せる
5. 問いかけの型：最後に「あなたの職場の一番の面倒は何ですか？」のように返信したくなる質問で終える（毎回ではなく、週2〜3回）

### 形式
- 画像はできるだけ毎回付ける（画像付きのほうが表示されやすい）。文章だけの投稿にも、内容に合った図解カードを付けてよい。本文と関係ない画像は付けない。
- リンク付き投稿は「画像＋説明文＋リンク」の形にする。リンクだけの投稿はしない。
- ハッシュタグは0〜1個。付けるなら内容にぴったりのものだけ（例：#業務効率化 #AI活用）。
- 「DMで聞いてください」は週1〜2回まで。売り込み口調にしない。

### 時刻
- 投稿は、見られやすい時間帯の中でランダムにする：朝7〜9時、昼12〜13時、夜19〜21時。1日2件の間は今まで通り3時間以上あける。

### 返信について
- X では自動返信はしない（X API の申請でそう約束しているため）。リプライが付いたら STATUS.md に「Xに返信が来ています（件数とURL）」と出すだけにする。返信は人が行う。
